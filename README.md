# Vertara
Transform any video into its vertical story.

## Video import

Vertara is browser-only: it never uploads or converts source video. MP4 and WebM files open directly, with MOV accepted when its codec is supported by the current browser. For the most reliable and immediate import, use an H.264/AVC video with AAC audio in an MP4 container.
